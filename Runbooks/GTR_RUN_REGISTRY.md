# GTR run registry

Status: **live reference — update whenever a run is launched, killed, or completes**

Maps every GTR run (GTR-L/Procoim, GTR-L/plain-AdamW, and GTR-ARW alike) to its log directory
and the config that makes it different from the others, so results never
get attributed to the wrong run. **Two task-length eras**, noted per row:
the original Procoim ablation runs (rows through `slot2_k1024_250k_seed0`)
share `--length 2`, `nodes=40/width=8/relays=4/streams=10`, `seed=0`,
`batch-size=144`, `hard-routing`, `--balanced-prefix-batches`,
`--prefix-loss-vocabulary valid`; every run from `slot2_length7_adamw_trace_seed0`
onward (the AdamW breakout/mastery investigation, the Transformer
baselines, and the GTR-L lever/topology variants) uses `--length 7`
instead, with its own shared base config noted in
`Runbooks/GTRL_ADAMW_BREAKOUT_LOG.md`. Only the columns below differ
between runs within each era.
